**Machine learning** เป็นหนึ่งในสาขาย่อยของ อัลกอริทึม-โครงสร้างข้อมูล ที่นักวิชาการทั่วโลกศึกษาและสอนในระดับอุดมศึกษา หัวข้อนี้ช่วยให้เข้าใจมุมมองเฉพาะทางและเชื่อมโยงกับสาขาอื่นได้

### ประเด็นสำคัญ

- complexity: แนวคิดพื้นฐานที่ควรเข้าใจก่อนศึกษารายละเอียด
- BFS: แนวทางที่ใช้จริงในการทำงานและการวิจัย
- DFS: จุดที่มักสับสน และวิธีตรวจสอบความเข้าใจ

### ตัวอย่างการนำไปใช้
ในงานจริง ให้เริ่มจากการระบุคำถามที่เกี่ยวข้องกับ Machine learning เลือกแนวคิดที่เหมาะสม แล้วทดลองใช้กับกรณีเล็ก ๆ ก่อนขยายผล การลงมือทำจะทำให้เห็นว่าส่วนใดใช้ได้ผลและส่วนใดต้องปรับ

### แบบฝึกหัดท้ายบท

1. อธิบาย Machine learning ด้วยภาษาของตนเองสั้น ๆ
2. ยกตัวอย่างงานที่ใช้ความรู้นี้ได้จริง
3. ข้อควรระวังหลักของหัวข้อนี้คืออะไร

### สรุป
บทนี้แนะนำ Machine learning ไว้แล้ว นำความเข้าใจนี้ไปเชื่อมกับบทอื่นในเล่มได้เลย

**Computer security and reliability** เป็นหนึ่งในสาขาย่อยของ อัลกอริทึม-โครงสร้างข้อมูล ที่นักวิชาการทั่วโลกศึกษาและสอนในระดับอุดมศึกษา หัวข้อนี้ช่วยให้เข้าใจมุมมองเฉพาะทางและเชื่อมโยงกับสาขาอื่นได้

### ประเด็นสำคัญ

- space: แนวคิดพื้นฐานที่ควรเข้าใจก่อนศึกษารายละเอียด
- array: แนวทางที่ใช้จริงในการทำงานและการวิจัย
- linked list: จุดที่มักสับสน และวิธีตรวจสอบความเข้าใจ

### ตัวอย่างการนำไปใช้
ในงานจริง ให้เริ่มจากการระบุคำถามที่เกี่ยวข้องกับ Computer security and reliability เลือกแนวคิดที่เหมาะสม แล้วทดลองใช้กับกรณีเล็ก ๆ ก่อนขยายผล การลงมือทำจะทำให้เห็นว่าส่วนใดใช้ได้ผลและส่วนใดต้องปรับ

### แบบฝึกหัดท้ายบท

1. อธิบาย Computer security and reliability ด้วยภาษาของตนเองสั้น ๆ
2. ยกตัวอย่างงานที่ใช้ความรู้นี้ได้จริง
3. ข้อควรระวังหลักของหัวข้อนี้คืออะไร

### สรุป
บทนี้แนะนำ Computer security and reliability ไว้แล้ว นำความเข้าใจนี้ไปเชื่อมกับบทอื่นในเล่มได้เลย

- hash table: แนวคิดพื้นฐานที่ควรเข้าใจก่อนศึกษารายละเอียด
- complexity: แนวทางที่ใช้จริงในการทำงานและการวิจัย
- BFS: จุดที่มักสับสน และวิธีตรวจสอบความเข้าใจ

### ตัวอย่างการนำไปใช้
ในงานจริง ให้เริ่มจากการระบุคำถามที่เกี่ยวข้องกับ Computing in social sciences, arts, humanities, and professions เลือกแนวคิดที่เหมาะสม แล้วทดลองใช้กับกรณีเล็ก ๆ ก่อนขยายผล การลงมือทำจะทำให้เห็นว่าส่วนใดใช้ได้ผลและส่วนใดต้องปรับ

### แบบฝึกหัดท้ายบท

1. อธิบาย Computing in social sciences, arts, humanities, and professions ด้วยภาษาของตนเองสั้น ๆ
2. ยกตัวอย่างงานที่ใช้ความรู้นี้ได้จริง
3. ข้อควรระวังหลักของหัวข้อนี้คืออะไร
